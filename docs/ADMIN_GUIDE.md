# 記事を書く人向けガイド

この文書は、記事を書く人や、内容の確認に参加する人向けの使い方です。記事を書くために必要な内容だけを、できるだけ簡単な言葉で説明します。画面上の「作業の進め方」からも同じ内容を確認できます。

## Atlasezの考え方

Atlasezが目指すのは、**一人一人の自学自習をみんなで支える学習サイト**です。知りたい・学びたいという気持ちから学びが始まり、学んだことを共有することで、次に学ぶ人のきっかけが生まれる。この考え方は、旧サイトから現在も変わっていません。

- 正確で、順序立てて整理された内容を無料で届ける。
- 「なぜ学ぶのか」「次に何を学ぶのか」が分かる記事にする。
- 定義や理由を大切にし、例だけで分かった気にならない説明にする。
- 図表や身近な例を使い、長い説明だけに頼らない。

## 記事を書くときの考え方

旧サイトで大切にしていた「記事案を出す → 記事を書く → ページを整える → 校正・推敲する → 公開する → 振り返る」という流れは、今も基本的に同じです。現在は、この流れを一つの編集画面で行います。

記事本文を書くほかにも、図や表を作る、誤字や内容を確認する、ページの見た目を考える、参考資料を探す、企画を考えるなど、さまざまな参加方法があります。活動頻度は週1〜2回程度を目安にしつつ、学校や仕事などと無理なく調整します。記事の一部だけ、図表だけ、確認だけの参加も歓迎しています。

## 1. まず開く画面

上のメニューから、次の画面を使います。

| 画面 | できること |
| --- | --- |
| 編集・査読 | 記事を探す、記事を書く、記事を直す |
| 記事編集 | 本文を書く、見た目を確認する、コメントを読む |
| 進捗・ToDo・日程 | 自分の作業、期限、予定を確認する |
| 問題報告・統計 | 読者から届いた記事の連絡を確認する |

ロゴやパンくずを押すと、前の画面へ戻れます。

## 2. 記事を書く・直す

1. 「編集・査読」で **新規記事作成** または **加筆・修正** を選びます。
2. 本文を書きながら、プレビューで見た目を確認します。
3. 「記事設定」に必要な項目を入力します。
4. **保存する**を押します。保存状態は画面上部で確認できます。
5. 作業を終えたら **査読を依頼する** を押します。
6. コメントが届いたら本文を直し、必要に応じて返信します。
7. 公開できる状態になると、画面に表示された **公開する** から公開できます。反映には少し時間がかかることがあります。

公開後に直したい場合は、画面に表示された公開取消の操作を使い、修正してからもう一度確認を依頼します。

記事の状態には「下書き」「査読中」「査読済み」があり、公開状態とは別に表示されます。

## 3. コメントの使い方

本文の気になる箇所をドラッグして選ぶと、その部分についてコメントできます。

- 「定義不足」「誤字」「脱字」などのタグだけでも送信できます。
- 返信には引用やタグを付けられます。
- `@` を入力すると、呼びかける相手の候補が出ます。
- 「確認済み」「未反映」などで、対応状況を伝えられます。

## 4. 数式と見た目

プレビューでは、数式を含む記事の見た目を確認できます。表示が崩れたときは、プレビューの方式を切り替えて見比べてください。数式の入力方法が分からない場合は、近い内容の記事を参考にするか、コメントで質問してください。

## 5. ToDo・予定・進捗

「進捗・ToDo・日程」では、次の情報を確認できます。

- 自分が担当する作業
- 自分が依頼した作業
- 自分が送った進捗報告
- 作業の期限、予定、参加できる日時

期限が近い順、期限切れ、今日までなどで絞り込めます。予定の時間帯が異なる人とも確認できるよう、タイムゾーンを選べます。

## 6. 問題報告と通知

読者からの記事の問題報告は「問題報告・統計」で確認します。自分の記事にコメントや確認が届くと、右上のベルに知らせが届きます。通知を既読にすると未読数からは消えますが、通知の記録は残ります。

問題を報告するときは、記事のURL、困った場所、状況を分かる範囲で書いてください。個人情報は入力しないでください。

## 7. 困ったとき

- 画面が読み込み中のままなら、ページを再読み込みしてもう一度試す。
- ログイン画面に戻った場合は、使っているGoogleアカウントを確認する。
- 公開した内容がすぐに見えない場合は、少し待ってから再読み込みする。
- 解決しない場合は、記事URL、行った操作、画面に出た文章を添えて相談する。

## 8. 参考資料の集め方

記事を書く前に、参考になる本・サイト・動画を探しておくと、説明の順序や例を考えやすくなります。旧サイトで使っていた資料の一覧も、必要に応じて確認します。

- 同じテーマの資料を複数見比べ、共通点と違いをメモする。
- サイト・動画・書籍を分けて記録する。
- 同じ題名の資料がないか検索してから追加する。
- 調べ終わった項目にはチェックを付ける。
- 資料をそのまま写さず、自分の言葉で整理する。
- 引用や画像を使うときは、出典と利用条件を確認する。

## 9. 一緒に作業する方法

数学・物理・化学・生物・天文・情報など、分野ごとに同じ時間に集まって作業することがあります。記事を書く、分からないところを相談する、文章を読み合うなど、参加方法は自由です。

1. 作業を始める前に「今日は何をするか」を短く共有する。
2. 質問するときは、記事のどの部分で困っているかを示す。
3. 終わるときに、できたことと次にすることを共有する。
4. 参加できない回があっても問題ありません。自分の予定に合わせて参加する。
