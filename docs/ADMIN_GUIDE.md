# 記事を書く人向けガイド

この文書は、記事を書く人や、内容の確認に参加する人向けの簡単な使い方です。専門的な設定や管理者だけの操作は載せていません。画面上の「作業の進め方」からも同じ内容を確認できます。

## 1. まず開く画面

上のメニューから、次の画面を使います。

| 画面 | できること |
| --- | --- |
| 編集・査読 | 記事を探す、記事を書く、記事を直す |
| 記事編集 | 本文を書く、見た目を確認する、コメントを読む |
| 進捗・ToDo・日程 | 自分の作業、期限、予定を確認する |
| 問題報告・統計 | 読者から届いた記事の連絡を確認する |

ロゴやパンくずを押すと、前の画面へ戻れます。

## 2. 記事を書く・直す

1. 「編集・査読」で **新規記事作成** または **加筆・修正** を選びます。
2. 本文を書きながら、プレビューで見た目を確認します。
3. 「記事設定」に必要な項目を入力します。
4. **保存する**を押します。保存状態は画面上部で確認できます。
5. 作業を終えたら **査読を依頼する** を押します。
6. コメントが届いたら本文を直し、必要に応じて返信します。
7. 公開できる状態になると、画面に表示された **公開する** から公開できます。反映には少し時間がかかることがあります。

公開後に直したい場合は、画面に表示された公開取消の操作を使い、修正してからもう一度確認を依頼します。

記事の状態には「下書き」「査読中」「査読済み」があり、公開状態とは別に表示されます。

## 3. コメントの使い方

本文の気になる箇所をドラッグして選ぶと、その部分についてコメントできます。

- 「定義不足」「誤字」「脱字」などのタグだけでも送信できます。
- 返信には引用やタグを付けられます。
- `@` を入力すると、呼びかける相手の候補が出ます。
- 「確認済み」「未反映」などで、対応状況を伝えられます。

## 4. 数式と見た目

プレビューでは、数式を含む記事の見た目を確認できます。表示が崩れたときは、プレビューの方式を切り替えて見比べてください。数式の入力方法が分からない場合は、近い内容の記事を参考にするか、コメントで質問してください。

## 5. ToDo・予定・進捗

「進捗・ToDo・日程」では、次の情報を確認できます。

- 自分が担当する作業
- 自分が依頼した作業
- 自分が送った進捗報告
- 作業の期限、予定、参加できる日時

期限が近い順、期限切れ、今日までなどで絞り込めます。予定の時間帯が異なる人とも確認できるよう、タイムゾーンを選べます。

## 6. 問題報告と通知

読者からの記事の問題報告は「問題報告・統計」で確認します。自分の記事にコメントや確認が届くと、右上のベルに知らせが届きます。通知を既読にすると未読数からは消えますが、通知の記録は残ります。

問題を報告するときは、記事のURL、困った場所、状況を分かる範囲で書いてください。個人情報は入力しないでください。

## 7. 困ったとき

- 画面が読み込み中のままなら、ページを再読み込みしてもう一度試す。
- ログイン画面に戻った場合は、使っているGoogleアカウントを確認する。
- 公開した内容がすぐに見えない場合は、少し待ってから再読み込みする。
- 解決しない場合は、記事URL、行った操作、画面に出た文章を添えて相談する。

詳しい開発・管理の情報は、利用者向け画面には表示せず、開発担当者向けの別資料で管理します。
