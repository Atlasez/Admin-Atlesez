## 指摘外で変更した点

- **デザイントークンの余白を全面圧縮**（`src/styles/tokens.css`）。`--space-3` 1rem→0.875rem、`--space-4` 1.5→1.25rem、`--space-5` 2.5→1.75rem、`--space-6` 4→2.5rem。全ページに効きます。
- **行間を 1.85 → 1.75 に**。日本語の可読性は保ちつつ、1 画面に入る行数を増やす狙い。
- **`--content-width` を 72rem → 78rem に拡大**。ワイド画面で一覧性が上がります。
- **記事本文の見出し・段落の余白を個別調整**。`h2` 上マージンを space-5→space-4、`h3` と段落にも明示的に狭いマージンを指定（従来はブラウザ既定の 1em 依存でばらついていた）。
- **`main` の上下パディングを space-4 → space-3**。
- **トップページの見出し階層を修正**。従来はサイト名が `h1`、分野が `h2`、分野名が `h3` でしたが、リード部を消したため「分野」を `h1`、「最近更新された記事」を `h2` に。分野名は見出しではなくリンクのリストにしています（スクリーンリーダーでの一覧走査がしやすいため）。
- **英語版のベータ告知文を修正**。「現行サイト」への言及を削除し、日本語版へ誘導する文面に変更。
- **カテゴリページの「準備中」記事の説明文**から「現行サイトの目次に掲載されている」を削除し、「目次に予定されている」に変更。
- **未使用になった CSS を削除**（`.subject-external-link` など）。
- `versions/` を tsconfig / eslint / prettier の対象外に追加。

## 未対応・要相談

- 「最近更新された記事」の日付が全件 2026/7/22 で並んでいます（一括インポート由来）。実際の更新日が入るまで日付の情報価値はほぼゼロなので、いずれ非表示にするか実日付を入れるか決めたいところです。
- 運営紹介ページは残しています。完全に消す場合は `src/pages/atlas/[locale]/team/` を削除し、`tests/e2e/main-pages.spec.ts` と `tests/e2e/accessibility.spec.ts` から該当テストを外す必要があります。
- 分野タイルの「?」は現状 JS でその場に説明を開く方式です。将来「〇〇学とは」の解説記事ができたら、リンク先をその記事に差し替えるのが自然だと思います。
