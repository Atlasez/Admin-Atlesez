# 概念グラフと学習地図

このサイトの「前提記事」「関連記事」「次に読む」「学習地図」「学習ルート検索」は、
すべて `src/content/concepts/concepts.yaml` の 1 つのデータから作られています。
記事側に手でリンクを書く場所はありません。

---

## 1. データの形

```yaml
- id: math.linear-algebra.vector-space # 永続ID: <接頭辞>.<カテゴリ>.<名前>
  subject: mathematics
  category: linear-algebra
  name: { ja: 線形空間 }
  prerequisites: [math.set-theory.mappings]
  recommendedNext: [math.linear-algebra.linear-map]
  related: [math.group-theory.group-definition]
  alternatives: []
```

ID の接頭辞は分野スラッグと一致しないものがあります（歴史的な経緯）。

| 分野        | 接頭辞                                                     |
| ----------- | ---------------------------------------------------------- |
| mathematics | `math`                                                     |
| chemistry   | `chem`                                                     |
| それ以外    | 分野スラッグそのまま（`physics`, `biology`, `kanji`, ...） |

### 線の種類

| 種類              | 意味                             | 向き | 使われ方                           |
| ----------------- | -------------------------------- | ---- | ---------------------------------- |
| `prerequisites`   | これを先に理解している必要がある | 有向 | 「前提記事」・学習ルート検索の骨格 |
| `recommendedNext` | 読んだ後に進むとよい             | 有向 | 「次に読む」                       |
| `related`         | 関連している                     | 無向 | 「関連記事」・分野をまたぐつながり |
| `alternatives`    | 別の説明・別経路                 | 無向 | 学習ルートの代替候補               |
| `partOf`          | 包含（現在は未使用）             | 有向 | ―                                  |

**`related` は両側に書いてください。** グラフ描画では無向として扱いますが、
記事ページの「関連記事」は自分の概念の `related` しか見ないためです。

**`prerequisites` に循環を作らないでください。** ビルドと
`node scripts/validate-content.mjs` が検出して止めます。

---

## 2. 学習地図の見え方

154 概念を一枚に描くと読めないため、2 段階の掘り下げにしています。

| 段階 | 描くもの                                       | ノード数      |
| ---- | ---------------------------------------------- | ------------- |
| 概要 | カテゴリの箱を、分野ごとの色枠の中に並べる     | 24 + 分野枠 7 |
| 詳細 | 選んだカテゴリの項目と、外につながっている項目 | カテゴリ次第  |

- 概要の線は、概念どうしの線を**カテゴリ単位に集約**したものです
- カテゴリを押すと詳細に入ります。前提のない項目が左、そこから学ぶ項目が右
- 詳細で点線の枠になっている項目は別カテゴリのもの。ダブルクリックで移動します
- 表示状態は URL に残ります（`?category=chemistry/matter`）

グラフは表示手段の1つです。地図の枠内に学習ルート検索があり、総合ホームには
独立したリスト表示があります。以前地図内にあったリスト表示・表形式は、横幅と
HTML容量を使うため削除しました。JavaScriptが動かない環境では、総合ホームの
リスト表示へ案内します。

実装は `src/components/LearningMap.astro`（総合ホームと地図ページで共用）、
ページは`src/pages/atlas/[locale]/map/index.astro`、
グラフデータの配信は `src/pages/atlas/graph.json.ts` です。

## 3. 線を足すときの考え方

### 同じカテゴリの中

**足さなくてよいことが多いです。** 地図ではカテゴリの箱が同じであること自体が
まとまりを表すため、内部を線で埋めると見づらくなるだけです。
学ぶ順番が実際に決まっている場合だけ `prerequisites` を足してください。

### 分野をまたぐとき

**積極的に足してください。** ここがこのサイトの見せ場です。
根拠を持って結べる組だけを選びます。現在入っているもの:

| つながり                                        | 根拠                                 |
| ----------------------------------------------- | ------------------------------------ |
| 空間と時間の性質・座標系 ⇄ 線形空間             | 座標系は線形空間として定式化される   |
| 座標系の変換 ⇄ 線形写像                         | 座標変換は線形写像そのもの           |
| 物質量・モル ⇄ 物理量                           | 物質量は SI 基本量のひとつ           |
| 化学結合・分子間相互作用 ⇄ 運動エネルギーと仕事 | 結合エネルギーは仕事の考え方に基づく |
| 脂肪酸・脂質 ⇄ 化学結合・分子間相互作用         | 脂質二重層は分子間相互作用で保たれる |
| 脂肪酸・脂質 ⇄ 溶解と溶液                       | 親水性・疎水性は溶解の理解が前提     |
| 星 ⇄ 原子の構造                                 | 恒星のスペクトルから元素を読み取る   |
| 星 ⇄ 空間と時間の性質・座標系                   | 日周運動の記述には天球座標が要る     |

追加は `scripts/add-cross-subject-links.mjs` の配列に足して実行するのが安全です
（両側への書き込みと重複除去をやってくれます）。

### やってはいけないこと

**掲載順を `recommendedNext` にしないでください。**
旧サイトからの移行時にこれをやってしまい、漢字 78 概念が
「次に学ぶ項目」という名前の一本道（最大 40 ノード）になっていました。
2026-07-26 に解体済みです（`scripts/restructure-kanji-graph.mjs`）。

`recommendedNext` は「これを読んだ人が次に進むとよい」という編集判断です。
単に隣に並んでいるだけの項目は結ばないでください。

## 4. 状態を確かめる

```bash
node scripts/validate-content.mjs   # 参照切れ・ID重複・prerequisites の循環
```

グラフの統計を見たいときは Node で直接読むのが早いです。

```bash
node --input-type=module -e "
import fs from 'node:fs'; import {parse} from 'yaml';
const cs = parse(fs.readFileSync('src/content/concepts/concepts.yaml','utf8'));
const kinds = {};
for (const c of cs) for (const k of ['prerequisites','recommendedNext','related'])
  kinds[k] = (kinds[k]||0) + (c[k]||[]).length;
console.log('概念', cs.length, kinds);
"
```

現在（2026-07-26）: 概念 154 / カテゴリ 24 / 前提 80・推奨 21・関連 55 /
分野をまたぐ参照 17。

## 5. 既知の弱いところ

- **漢字の 54 概念は線を持ちません。** 前提関係が本質的にないためで、
  地図ではカテゴリの箱にまとまって見えます。意味の近い組だけ 14 組結んであります
- **記事のない概念が 5 件あります**（すべて数学）。地図には出ますが行き先がありません。
  記事ができるまでの状態です
- **`partOf` は未使用**です。カテゴリ階層は地図側で描いており、データには持たせていません
