### さむい

#### 【一字】

| 漢字 | 読み             |
| ---- | ---------------- |
| 寒   | さむ-い          |
| 冱   | こお-る、さ-える |
| 凊   | すず-しい        |
| 滄   | つめ-たい        |
| 冽   | つめ-たい        |
| 洌   | つめ-たい        |
| 淒   | つめ-たい        |
| 凜   | つめ-たい        |

#### 【熟語】
